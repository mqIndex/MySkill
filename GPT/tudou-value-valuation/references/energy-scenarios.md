# 煤油情景扩展：与通用评分法分别使用

来自用户在本会话提供的“煤油量化估值系统简单估算”截图。作者说明未涵盖全部，采用长期780元煤价、85美元油价。

该表是多方法、多情景加权；不要直接套用通用评分表的历史PE/PB及15%–30%买入要求。用户要求整合时，说明口径不同，把整合规则标为新假设。

方法权重明确：盈利能力35%、所有者收益30%、股息回报20%、PB–ROE 15%。内部公式和收益率/折现率未展示，不能把盈利能力法擅自定义为特定PE公式。

```text
单情景价值 = 35%×盈利能力价值 + 30%×所有者收益价值
           + 20%×股息回报价值 + 15%×PB–ROE价值
概率加权中枢 ≈ 25%×悲观价值 + 50%×基准价值 + 25%×高价延续价值
中枢潜在价格回报 ≈ 中枢 / 现价 - 1
```

25%/50%/25%按多行数值反推，未获作者明确确认。神华35.18×25%+37.07×50%+39.61×25%≈37.23。

“大买线”约中枢55%–70%，不同公司不同，依据未披露，不得绑定成通用质量评分公式。

中国石化的悲观4.76、基准4.54、高价延续4.33，表明不能统一假设商品价格与所有公司价值正相关，原因需检查业务与公式。商品价格与额外盈利系数是否重复计算同一风险也需核对。

资料不足时可以记录或评价框架，做明确假设的敏感性分析；不能声称完整复建了煤油底层模型。
