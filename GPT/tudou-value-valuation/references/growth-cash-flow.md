# 成长估值、DCF与反向DCF

## 来源及适用方式

价投小猪仔：[《【被拉黑了】听说药明估值高》](https://www.bilibili.com/video/BV11maB6iEDD/)，发布于2026-10-01。本会话2026-10-10通过用户已登录Chrome读取估值画面、字幕及简介，数据基准为2026-09-30。下述历史数字用于记录方法，未来分析应重新取得数据。

作者用历史分位、同业比较、PEG、DCF交叉评价估值，重点把争论转换成可验证的增长假设；没有给固定买入折扣。土豆质量评分与折扣沿用主文件，将二者组合属于本skill的整合约定。视频中对SOTP、PS、EV/EBITDA和清算价值的限制主要针对药明康德，不能泛化为这些方法对其他公司都无效。

## 输入与方法选择

遵守主文件的用户讨论规则：本文件给出计算方式和历史示例，不预先批准任何公司当前的增长率、10%折现率、3%永续增长、五年分段或情景权重。先按具体经营证据提出选项及敏感性，待用户认可关键假设后确定基准；原作者复现和待讨论候选试算可先完成。

先理解公司卖什么、利润是否可重复、是否仍在扩产、资本回报和现金转化如何，再选价值锚。历史分位、同行估值和PEG是参照，不自动成为内在价值。整合时不叠加没有出处的“成长加分”或第二套质量扣分。

历史分位注明起止日、窗口、PE类型和可比业务；高估时期进入样本可使当前分位显低。同行同日、同口径比较，注明净亏损或利润低谷扭曲。各家公司须使用自身增长、资产和风险参数，不移植药明康德数字。

PEG = PE / EPS增长率的百分数值。增长期匹配预测PE的盈利基期，并考察多年的可持续性、稀释、基数及增长所需再投资。增长≤0时不强行计算正常PEG。收入、归母利润、扣非利润、EPS与自由现金流的增速均分别报告；只有能说明利润率、再投资和股本桥接关系时，才能建立转换假设。

## DCF模型与计算纪律

选择并声明现金流定义，不将公司经调整自由现金流未经调节直接当FCFF或FCFE：

- FCFF用与其风险匹配的WACC折现，所得经营企业价值，加非经营资产、减净债务及其他优先索取权后得到普通股价值。
- FCFE用权益资本成本折现，所得已是权益价值；融资、利息和债务偿还已在现金流中处理，不能再次机械减同一净债务。非经营现金是否另加，取决于其收益是否已在预测中计入。
- 使用公司公布的经调整FCF做代理时，核对调整项目、利息、租赁、股权激励、营运资本、维护与扩张资本开支，声明近似范围。扣非利润不能自动等同现金流。

公开现金流基年、每段增长及年数、折现率r、永续增长g、年末/年中折现、资产债务调整、股数、币种和估值日。基年用已实现值或管理层指引时注明；指引不等于确定经营结果。基年预测若包含未来期间，说明折现起点，避免整年未来现金流与时点混用。

年末折现的通用计算：

```text
CF_t = CF_(t-1) × (1 + 当段增长率)
经营现值 = Σ[CF_t / (1+r)^t] + 终值 / (1+r)^N
永续终值 = CF_N × (1+g) / (r-g)，要求r>g
每股价值 = 调整后的普通股权益价值 / 对应股数
```

显式期可按企业特点分段，视频的“五年+五年”不是固定通则。“后五年增速减半”及永续3%属于作者假设，不属于公司指引。终值中的再投资、长期利润率和资本回报须支持永续增长；高增长需要投入，不能只增加现金流而省略其资本需求。

至少给基准及合理的上下行情景。对基年现金流、增长、折现率、永续增长分别作敏感性分析，列出终值占比。政策风险可以进入受损情景、现金流或折现率，说明处理位置；不要无解释地在增长、折现率和买入折扣重复扣同一风险。情景概率没有可解释依据时不计算概率加权目标价。

用计算工具复算，明确精度。输入或原作者结果无法复现时列差异，不把作者表上的所有数字标成已验证。

## 反向DCF与证据验证

把现价代入，固定基年、折现率、终值、资本结构、股本和其他增长段，求模型每股价值等于现价时的未知增长率。用可解释范围内的数值求根；若无解、非唯一或目标函数不单调，报告限制。若同时把后段增速绑定为前段的一半，须明确该联动。

输出“在这些假设下，现价要求的增长率”，不要把它称为市场唯一真实预期。变动基年现金流、折现率和终值后重算隐含增长，判断结论对模型依赖程度。

证据清单对应所求现金流或EPS：收入与订单、利润率、收现、营运资本、资本开支、产能爬坡、稀释、客户或政策变化。单年收入指引只能支持近期收入假设；不能直接证明未来五年现金流CAGR。注明下一份财报或事件的可验证指标；没有用户请求就不启动后台监控。

## 药明康德历史示例与口径纠正

视频2026-09-30 A股现价167.34元。按视频披露，报表PE-TTM23.44、扣非PE-TTM27.86；上市以来报表PE历史分位约35.6%，不能当成已核验的最近3年扣非分位。PEG按所假定增速约0.46–1.4，不是单一确定结论。

作者DCF以经调整FCF指引中值140亿元作基年、净现金456亿元、股数30.35亿股、折现率10%、一般情景永续增长3%。中性情景前五年20%、后五年10%；年末折现可复算每股185.70元。乐观前五年25%、后五年12.5%可复算240.11元。隐含前五年增速约18%、后五年联动为其一半时，每股约167.63元，与视频的18%近似一致。这些是模型假设，不是当前估值或回报承诺。

视频情景页给悲观115.5、零增长61.2、地缘受损45.1元。按页面简化注释中悲观前五年12%、后五年减半、永续3%及上述其他输入，复算约123.71元，与115.5不同；可能有未展示的参数差异，不能擅自补全或宣称全部复现。零增长和受损情景另用永续0%，须单独列参数。

作者将“未来五年FCF年增18%”与“公司指引35%–39%”并列。经[公司2026年半年业绩公告](https://www.wuxiapptec.cn/en/news/wuxi-news/wuxi-apptec-delivers-strong-h1-2026-results-and-raises-full-year-guidance-driven-by-greater-success-of-multiple-customers-products-and-crdmo-model)核对，35%–39%为2026全年持续经营收入同比增长指引；调整后FCF指引为135–145亿元。二者期限与指标不同，不能用35%–39%直接证明五年FCF增长18%。视频用该收入增速作PEG分母时，应标为非标准的增长参照，不能冒称可持续EPS增速。
